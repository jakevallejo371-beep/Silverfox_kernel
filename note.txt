C compilation flags:
-ffreestanding -> 	     tells gcc there's no standard library, no main() guarantees, no hosted environment. Without this, gcc assumes things like malloc/printf exist and may "optimize" code into calls to them.
-fno-pie ->		     stops gcc emitting position-independent code (relies on a dynamic loader you don't have).
-fno-stack-protector ->     disables stack-canary checks that call __stack_chk_fail, a libc function you don't have.
-mno-red-zone ->	     only matters in 64-bit mode, but include it if you ever go x86_64; the red zone gets clobbered by interrupts on bare metal.
-nostdlib (at link time) -> don't link against libc/crt0.
-m32 ->                           since your boot.asm is bits 32, keep the kernel 32-bit too, otherwise you'll get calling-convention/pointer-size mismatches between the two object files.
